# Preserved prototype

`prototype/` contains the pre-restructure Gemma/Metal application as its own Cargo
workspace. Its original source and documentation are preserved; run commands from
that directory. It is excluded from the new root Cargo/npm workspaces and is not
an active product dependency.

The local branch `archive/gemma-prototype` points to the original commit. The
source here also survives normal clones without depending on that branch.
